# Vendored contract: article.schema.json (v1)

This is a pinned, byte-identical copy of the platform's publish contract,
`contracts/article.schema.json` from the `censurado-web` repository. It is the
single cross-layer contract for the article payload the harness publishes.

- Schema `$id`: `https://censurado.local/contracts/article.schema.json`
- Source repo: `censurado-web` (the reading platform)
- Source path: `contracts/article.schema.json`

Do not edit this file by hand. It is governed by a drift test
(`tests/test_schema_drift.py`) that compares it to the live platform schema and
fails loudly when the two diverge. To re-sync after an intentional platform
schema change, copy the platform file over this one and bump `CONTRACT_VERSION`
in `newsroom/contracts/schema.py` when the change is breaking.
